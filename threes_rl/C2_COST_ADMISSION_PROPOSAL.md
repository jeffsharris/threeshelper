# Proposed C2: Deterministic Cost-Admitted Exact Depth 3

Status: proposal only; execution is not authorized.

## Motivation

C1 made the unchanged exact calculation fast in typical cases but failed p99
because a few states have very cheap depth 2 and much larger depth-3 trees.
Their absolute optimized latency was not exceptional. More generic cache work
is poorly motivated: exact leaf boards and chance contexts rarely repeat.

## Proposed Intervention

Keep the incumbent and retained C1 calculation immutable. Add a deterministic
pre-search cost admission rule after depth 2:

- collect exact, outcome-free depth-2 complexity counters already generated by
  search: legal actions, afterstate boards, chance branches, unique value states,
  empties, preview kind, and incumbent margin;
- use one preregistered monotone cost model to predict exact C1 combined work;
- run exact depth 3 only when predicted relative and absolute latency are within
  frozen limits; otherwise return the unchanged depth-2 action/value;
- never use measured wall-clock time as a policy input, and never truncate a
  depth-3 tree after admission.

This changes the adaptive operator, so it is C2 rather than a reinterpretation
of C1.

## Proposed Engineering Gate

1. Freeze a new source-diverse corpus disjoint from R2a, all C1 splits, and
   prior policy gates. Partition whole ancestries into cost-model fit,
   engineering validation, and untouched runtime gate before timing.
2. Fit exactly one nonnegative linear count model on engineering timing only.
   Freeze features, regularization, admission threshold, and minimum activity
   before opening validation. No policy outcomes or parameter sweep.
3. Require exact equality with depth 2 for rejected states and exact equality
   with retained C1 depth 3 for admitted states.
4. On the untouched runtime gate require median <=3x, p90 <=5x, p99 <=8x,
   max <=12x, absolute p99 <=2.5 seconds, no action/value mismatch, and depth-3
   admission on at least 15% of eligible states across at least three families.
5. If activity is below 15%, prediction is poorly calibrated, or the tail gate
   fails, kill C2 without relaxing thresholds.

## Conditional Policy Gate

Only an engineering PASS would authorize a separately frozen, root-disjoint
h10/h20/h40 causal prescreen comparing C2 against incumbent depth 2 on score,
first-1536/3072 hazard, survival, and anchor/top-edge endpoints. A positive,
no-harm prescreen would be required before any fresh normal-start development
block. Confirmation and dashboard rules remain unchanged.

## Honest Exit

If cost admission cannot retain useful activity, exact depth 3 is structurally
misaligned with the latency contract and should be abandoned. Do not respond by
tuning the C1 node budget, relaxing p99, or adding cache variants.

## Ranked Roadmap Options

1. **C2 cost admission:** highest probability of meeting latency while retaining
   exact depth 3 on a meaningful subset; requires fresh engineering and causal
   gates because the operator changes.
2. **Compiled exact leaf kernel:** preserve global depth 3 by implementing one
   fused native n-tuple lookup with frozen floating-point order. Mechanistically
   grounded in the 91% leaf-time share, but lower probability because C1's p99
   failure is primarily denominator-driven.
3. **Abandon exact depth 3:** keep depth 2 and wait for genuinely new information
   such as a third substantial assisted ancestry or a new representation/search
   family. This is preferable to another exact-search optimization cycle if C2
   activity is too low.

H3 remains held until at least three substantial completed assisted ancestries
exist. Partial sessions are not evidence.
