# Steers For The Next Solver Iteration

These are the July 6 research steers for pushing beyond the current
corrected-start solver.

## 1. Close The Expert-Iteration Loop

Current value fits still use `corner2` as the actor, but learned-leaf search is
starting to beat `corner2` on held-out slices. The standing outer loop should
be:

1. Play games with the current best search policy.
2. Refit the value model on those trajectories.
3. Gate on paired eval.
4. Promote the student if it wins.

The immediate actor policy should be
`ntuple_expectimax2:<checkpoint>`, not more `corner2`.

## 2. Replace Pure MC With N-Step / TD(lambda)-Style Targets Plus TC

The alpha sensitivity in the MC runs is likely variance. Add lower-variance
n-step bootstrapping, and use temporal-coherence-style per-weight step scaling
so alpha tuning is less brittle.

## 3. Manufacture Late-Game Data

Median games still die early and there is little signal above non-starter
3072. Add high-board start-state reservoirs, bucketed around 768/1536/3072,
and make the training loop able to start some episodes from those states. Human
tracker replays should become a source of these boards.

## 4. Increase Value Capacity

Add a large six-tuple pattern set. The default rows/cols/2x2 setup likely
cannot represent enough corner-strategy geometry. Symmetry sharing remains
useful despite the fixed top-left starter.

## 5. Make Search Cheap Before Making It Deep

At preview-independent value leaves, next-preview enumeration is wasted: the
future value is identical across next previews. Prune that chance layer at leaf
targets and add transposition caching before revisiting deeper search.

## 6. Tighten Decision Hygiene

Use 50/100+ paired seeds before promotion decisions because scores are
heavy-tailed. Track median score-minus-starter as closely as mean. Run death
forensics before committing to each next experiment.
